# Cultura em Foco

Portal de notícias desenvolvido para a disciplina de Desenvolvimento Web 2.

## Descrição

O Cultura em Foco é um portal de notícias sobre cultura, música, tecnologia, literatura, cinema e cidade.

O projeto possui uma identidade visual própria e foi desenvolvido utilizando HTML5 semântico, CSS3 e JavaScript puro.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Paleta de cores

- Laranja principal: #E4572E
- Laranja escuro: #C94420
- Amarelo: #F3C969
- Fundo claro: #F7F4EE
- Branco: #FFFFFF
- Texto: #1D1D1B

As cores foram definidas utilizando variáveis CSS.

## Fontes

Foram utilizadas duas fontes:

- Playfair Display — utilizada nos títulos.
- DM Sans — utilizada nos textos, menus e informações.

As fontes são disponibilizadas pelo Google Fonts.

## Funcionalidades JavaScript

O projeto possui as seguintes funcionalidades:

1. Busca de notícias pelo título em tempo real.
2. Filtro de notícias por categoria.
3. Tema claro e escuro.
4. Persistência do tema utilizando localStorage.
5. Menu responsivo para dispositivos móveis.
6. Validação do formulário de newsletter.

## Estrutura HTML

Foram utilizadas as seguintes tags semânticas:

- header
- nav
- main

- article
- aside
- footer

## Acessibilidade

O projeto possui:

- atributo alt em todas as imagens;
- foco visível nos elementos interativos;
- HTML semântico;
- labels nos campos de formulário;
- aria-label;
- aria-live;
- contraste adequado.

## Responsividade

O projeto utiliza:

- Flexbox;
- CSS Grid;
- Media Queries;
- Breakpoints para tablets e celulares.
